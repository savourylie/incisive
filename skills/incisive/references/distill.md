# Playbook: distill

Strip away the scaffolding, background summary, and hollow self-promotion that accumulate during first-draft writing so only clean, reader-facing argumentation remains.

## Workflow

1. **Excise the Summary Trap**:
   - Identify extended stretches of plot summary, chronological background, or source paraphrase that do not advance a claim.
   - Compress essential context into brief analytical clauses woven directly into argument paragraphs.

2. **Purge Hollow Importance Words**:
   - Hunt down `important`, `crucial`, `essential`, `significant`, `very interesting`, `noteworthy`, `vital`, `key` when used to *tell* the reader something matters instead of *showing* why.
   - Delete the empty adjective and state the concrete stake, mechanism, or consequence in plain nouns and verbs.

3. **Cut Thinking-History Narration**:
   - Remove meta-commentary about how the writer approached the task ("In order to analyze X, we must first define Y", "When I began looking at this data, I noticed...").
   - Start directly with the analytical point.

4. **Tighten Paragraph Density**:
   - Cut throat-clearing lead-ins, repetitive restatements of the same point across consecutive paragraphs, and filler transitions.
   - Preserve every nuance, qualifier, and unpacked evidentiary bridge.

## Deliverable

Apply the distilled edits and report a brief compression summary (word count before/after + major cuts made).
